閱讀方式

  • 開工前先看增修紀錄的開工前待確認（七項），沒有答案的部分先不要動對應的程式。
  • 每一章先看「問題與方案」了解為什麼要做，再看規格表。
  • 章節結尾的驗收條件（☐）就是完成定義，測試案例照它寫。
  • 範疇外一節是明確不做的事，不要自行補。
  • 最近的變更：登入方式改為一次性驗證碼（OTP）、移除 2FA 備援碼、平台超管最少保留兩位。
